# Performanceanalyse

1. Miss einen definierten Ablauf unter dokumentierten Bedingungen.
2. Untersuche Netzwerk-Wasserfall, lange Tasks und Layoutverschiebungen mit Trace-Daten.
3. Ordne den größten Engpass einer konkreten Ressource zu und vergleiche nach einer Änderung denselben Ablauf.

## Ergebnis

Messbasierte Engpassanalyse mit Vorher-/Nachher-Beleg.
